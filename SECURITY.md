# Security Policy

Please report security issues privately to the maintainers instead of opening a public issue.

## Scope

In scope:

- Secret leakage.
- Auth, authorization, and tenant-boundary bypasses.
- Connector credential exposure.
- Prompt-injection paths that bypass Merlin policy.
- Plugin/action escalation issues.

Out of scope for the public repo:

- Avalon private integrations or production data, which must remain outside this repository.

## Supported versions

Until the first tagged release, security fixes target `main`.
